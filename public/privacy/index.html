Privacy for local files and labels

Effective 5 September 2026. Color Context stores your work in this browser.

What is stored

Files you open, labels you add, and recent-workspace details are stored in IndexedDB. Your display preference is stored in local storage.

Demo data

The demo uses a separate demo: browser-storage namespace. Resetting the demo or starting for real removes the sample workspace. It never reads or changes your real work.

Exports

Your data leaves the browser only when you download an annotated PNG or workspace JSON and choose to share it. A workspace export includes its source file and labels.

Network activity

The app loads its own static files from color-context.sociobot.in. It has no advertising, analytics, tracking pixels, remote fonts, third-party scripts, accounts, or document uploads.

Deleting data

Use “Remove file” to delete a saved file and its labels. Clearing this site’s browser storage removes all local workspaces and preferences.

Contact

Report a privacy question on the project repository (opens GitHub).

Files and labels stay in this browser unless you export them.
